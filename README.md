# 🎨 Smart Wall Painting Robot

An Arduino-based robotic system designed to automate wall painting using omnidirectional movement, sensor-based navigation, a controlled painting mechanism, and a Bluetooth-controlled mobile application.

---

## 📌 Project Overview

The **Smart Wall Painting Robot** is a robotic system developed to automate wall-painting operations. The project combines mechanical design, embedded systems, sensor integration, motor control, and wireless communication to create a functional wall-painting prototype.

The robot uses **Mecanum wheels** for omnidirectional movement and integrates rotary encoders, ultrasonic sensors, and a color sensor for movement tracking, obstacle detection, wall-distance measurement, and surface color detection.

A custom mobile application developed using **MIT App Inventor** communicates with the robot through a **Bluetooth module**, allowing the user to wirelessly control the robot's movement, painting actions, and operating modes.

---

## 🚀 Key Features

* Omnidirectional movement using **Mecanum wheels**.
* Wireless control through a **Bluetooth-enabled mobile application**.
* Obstacle detection and wall-distance measurement using ultrasonic sensors.
* Movement and distance tracking using rotary encoders.
* Surface color detection using the **TCS3200 Color Sensor**.
* Controlled paint delivery using a mini water pump and nozzle.
* Precise vertical movement using a **NEMA 17 stepper motor**.
* Custom mobile application developed using **MIT App Inventor**.
* Arduino-based control and integration of the robotic system.

## 📱 Mobile Application

A custom mobile application was developed using **MIT App Inventor** to provide a user-friendly interface for controlling the robot.

The application communicates with the robot through a **Bluetooth module** and allows the user to:

* Control robot movement.
* Operate the painting mechanism.
* Switch between operating modes.
* Wirelessly control the robot using a mobile phone.

Images of the application's control logic are available in the `images` folder.
